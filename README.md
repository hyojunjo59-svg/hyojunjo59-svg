### Senior Systems & Security Software Engineer

Seoul, South Korea | Independent Systems Lab

Passionate about low-level runtime architecture, high-performance concurrency, memory safety, and secure systems engineering. Designing resilient, production-grade software where mechanical sympathy, predictability, and uncompromising code quality are paramount.

---

### Core Engineering Principles

- **Deterministic Correctness**: Eliminating undefined behavior, data races, and state ambiguity through strong type systems, comprehensive test suites, and strict formal verification.
- **Performance & Mechanical Sympathy**: Designing cache-friendly data structures, zero-cost abstractions, and direct memory layouts that fully leverage modern hardware capabilities.
- **Defense in Depth**: Enforcing the principle of least privilege, strict trust boundaries, and resilient fault domains across process, memory, and network layers.
- **Pragmatic Craftsmanship**: Writing clean, readable, and thoroughly audited code. Rejecting unnecessary third-party dependencies, fragile abstractions, and unvetted complexity.
