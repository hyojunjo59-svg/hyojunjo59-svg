### Systems & Security Software Engineer

Seoul, South Korea | Independent Systems Lab

Focusing on low-level runtime architecture, deterministic verification systems, zero-overhead tooling, and native security auditing. Building resilient primitives where predictability, mechanical sympathy, and verification integrity are fundamental requirements.

---

### Core Engineering Principles

- **Deterministic Correctness**: Elimination of undefined behavior, memory corruption vulnerabilities, and state ambiguity through strict type systems, formal assertions, and reproducible test suites.
- **Zero-Cost Abstractions**: Maximizing runtime efficiency by leveraging compiler-driven optimizations, direct memory layouts, cache friendliness, and minimal runtime indirection.
- **Minimal Attack Surface**: Designing isolated security boundaries, enforcing least privilege, and applying zero-trust verification across network, process, and memory domains.
- **Orthodox Craftsmanship**: Writing clear, maintainable, and inspectable code. Rejection of unvetted bloat, fragile dependencies, and non-deterministic heuristics.
